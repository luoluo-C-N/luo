掌上小站 · 全功能管理 App 原型

对应网站「洛洛の小站」（Kirameku），覆盖 Web 后台全部管理能力。
  • 多面板工作台：屏幕左缘右滑打开侧边栏（丝滑跟手），侧边栏 = 身份卡 + 面板切换器
  • 面板卡片：只显示图标 + 名字，左滑渐变出 置顶 / 启停 / 关闭；点头像进账号中心（退出登录在这里）
  • 网站面板(默认)：状态(中间突出，CPU/内存/磁盘、服务、端口) / 看板 / 内容 / 审核 / 我的
  • 学习面板：今日 / 课程 / 笔记 / 统计 —— 演示第二套导航体系
  • 快速发布：各页右上角 ＋ 呼出半屏面板(仅网站面板) · 子页：编辑器、模块管理
  • 工具类功能已并入「我的 › 扩展工具」
