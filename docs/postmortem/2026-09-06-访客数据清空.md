## 3. 根因（5-Why）

1. **为什么数据被清空？** 因为 `DELETE /api/visitors` 在旧代码中完全无鉴权，请求直接执行。
2. **为什么打到旧代码？** 因为 8000 的重启失败（用错 Python 解释器），而失败未被察觉。
3. **为什么失败未被察觉？** 因为重启后没有验证服务是否真的起来了，直接开始探测。
4. **为什么要在 8000 上探测破坏性接口？** 因为当时没有"破坏性验证必须走隔离环境"的强制约束，只有口头默契。
5. **为什么没有备份？** 因为从未把"生产库备份"列为流程要求（R2）。

**根本原因**：缺乏强制性的环境隔离与操作门禁，关键约束依赖个人自觉与口头约定。
