# 掌上小站 0.01 设计与验收

用户授权 Codex 与 GLM 自主决策，工作目录固定 E:/glm/appkf。保留原 ui-design 文件；聊天室与项目速览由协作者持续维护。

## 选型
比较三种路径：Flutter 全面重写需重新实现玻璃/手势；React Native 重写同样成本高；现有 Web 交互工程化 + Capacitor 直接复用已验证视觉，且支持 Android 与 PWA。选择第三种。版本号 0.0.1，对外称 0.01。桌面浏览器也能预览，手机取消原型机壳，适配 safe-area 和软键盘。

## 功能要求
1. 后端连接可配置，默认本机同源代理；所有请求超时、非成功状态、过期登录须显示明确错误，禁止失败后演示数据冒充在线数据。
2. 真实管理员登录、退出、会话过期处理；令牌只向配置的后端发送。
3. 系统状态与真实看板，明确单位、加载/失败/空状态和刷新时间。
4. 文章列表、搜索、分页、详情、新建/编辑、草稿与发布；本地草稿恢复，只有成功请求后标记云端已保存。
5. 评论/留言审核；音乐列表/播放/上传/删除；说说、相册及基础管理 CRUD 由 GLM 交付后集成。
6. 多面板、模板和沙盒代码模块、分享码、重命名、壁纸、深色模式保留。学习面板明确本地/演示性质，不伪造云端同步。
7. PWA 清单和离线应用壳，不缓存认证/API；Android Capacitor 工程与可复现打包脚本，优先实际生成 APK。
8. 使用副本数据库/测试服务做写入验证，不删除用户已有数据。交付使用说明、验证报告、版本进度与已知限制。

## 验收
执行 API 单元测试（裸数据/信封/401/错误/超时）、真实后端契约检查、浏览器手机尺寸及键盘/抽屉/主题/草稿/审核等端到端检查；构建生产包；Android 如可构建则校验 APK 并进行模拟器/设备验证。有缺项不宣称全部完成。
